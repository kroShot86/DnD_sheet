                    Лист персонажа

Действия:
1) Поменять характеристики (сейчас влияет только телосложение (на хп))
2) Получить урон
3) Отхилиться

Состояния:
1) Здоров (> 0 хп)
2) Без сознания (0 хп)
3) Мертв (получить урон после 0 хп)
